                        RESISTOR COMBINATION CALCULATOR


What it does


This is a python program that calculates the total resistance connected in series or parallel. It asks the user to enter the number of resistors and their individual resistance values.

How to run it
1. Instal pyton 3.
2. Open the project folder in VS Code.
3. Open terminal.
4. Run: python 
    resistor_calculator.py

Sample output

Series Resistance:600.0 ohms
Parallel Resistance: 54.55 ohms
Series resistance is higher


My own twist

i added a comparison feature that identifies wether series or parallel resistance is higher. I also included input validation to handle invaid entries.
